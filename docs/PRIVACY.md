# Privacy (App Store–oriented draft)

Use this as source copy for App Store Connect / in-app privacy labels. Adjust with legal review before submission.

## Summary

Weepo is a **companion chat app**. By default it works **offline** (canned replies + on-device speech). Optional **Bring Your Own Key (BYO)** LLM sends chat text to the API URL you configure.

## Data stored on device

| Data | Where | Leaves device? |
|------|--------|----------------|
| Chat history per persona | AsyncStorage | No |
| Memory notes | AsyncStorage | No |
| LLM base URL, API key, model | AsyncStorage | Key used only for your chosen API |
| Voice settings (TTS on/off, rate, locale) | AsyncStorage | No |

Weepo does **not** operate a Mon Mon cloud backend for chat in this MVP.

## Data sent to third parties (user-controlled)

When **LLM slot** is enabled and configured:

- Message text (recent turns + your new message) is sent to **your** OpenAI-compatible provider (e.g. OpenAI, DeepSeek, local gateway).
- Weepo does not embed vendor API keys in the app binary.

When **Speak replies** is on:

- Assistant reply text is sent to the **OS text-to-speech engine** (Apple AVSpeech on iOS). No separate cloud TTS key in M4.

## Not collected in MVP

- Account / email (no login)
- Analytics SDK (none shipped)
- Advertising ID
- Precise location
- Contacts / photos

## Microphone

Mic button is a **stub** in M4. No audio is recorded until a future STT build adds `NSMicrophoneUsageDescription` usage.

## User controls

- Disable LLM → offline-only replies
- Clear memory notes in Settings (manual delete per note — bulk clear can be added later)
- Uninstall app → AsyncStorage removed with app

## AI disclosure (suggested in-app line)

> Replies are generated by AI. This companion is not a human and is not a substitute for professional advice.

Place in Settings / About (see Settings screen).
